# Contributing to OWA Coding Pattern

We welcome improvements that make the pattern more reliable or cheaper without adding theater.

## How to Contribute

1. Open an issue first for any non-trivial change.
2. Keep changes focused and minimal.
3. Update both `index.html` and `README.md` when modifying content.
4. Test that the HTML still renders cleanly.

## Style

- Dry, precise, first-principles tone.
- No moralizing.
- Prefer concrete rules over vague advice.
